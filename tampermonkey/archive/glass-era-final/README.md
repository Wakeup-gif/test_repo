# Final Glass-era SquareCoil scripts

This folder freezes the exact working Glass-era set immediately before the canonical Tampermonkey scripts were promoted to the graphite Dark Glass system.

These files are archive/reference copies only. They intentionally keep their historical metadata and are not the live Tampermonkey update endpoints.

## Live update endpoints

The active scripts remain at `tampermonkey/<canonical-name>.user.js`. Existing Tampermonkey installs continue updating from those canonical raw GitHub URLs.
